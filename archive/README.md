# Local software archives

`archive/builds/` is an ignored, local holding area for superseded project software. It is not part of source publication or release ZIPs. No archive contents are discovered or cleaned by the publication tools.

Keep active user guides under `docs/`; curated synthetic-only development evidence and the design audit live under `docs/development/`. Obsolete drafts are omitted from the public source snapshot. Operator files, settings, workspaces, reports, and checkpoints are outside repository cleanup scope.
